## 2026-04-08 - Native HTML5 Validation in Next.js\n**Learning:** When using native HTML5 validation (like `required` attributes) on a form in a Next.js application, simply changing the submit button to `type="submit"` will cause a full page reload if the form successfully validates, which disrupts the Single Page Application (SPA) experience.\n**Action:** Always wrap the inputs in a `<form>` tag and ensure an `onSubmit={(e) => e.preventDefault()}` handler is attached to the form. This combination allows the browser's native validation UI to trigger properly while preventing the default form submission reload behavior.
