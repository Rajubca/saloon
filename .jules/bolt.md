## 2024-05-24 - Unthrottled Scroll Event Listeners causing main-thread load
**Learning:** Continuous scroll event listeners without throttling or debouncing, especially those evaluating DOM properties (like `document.body.scrollHeight` or `document.getElementById('home')?.offsetHeight`), can cause layout thrashing and significant main-thread CPU usage during scrolling. Synchronous `setState` calls inside these handlers can also lead to unnecessary React re-renders.
**Action:** Always wrap scroll event logic inside `requestAnimationFrame` to limit execution to the browser's paint cycle. Use the functional form of `setState` (`setScrolled((prev) => prev !== newValue ? newValue : prev)`) to prevent unnecessary React state updates. Also, mark the event listener as `{ passive: true }` to avoid blocking scroll performance.
