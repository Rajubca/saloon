## 2023-10-27 - [Scroll Event Layout Thrashing]
**Learning:** The application uses scroll event listeners in `Navbar.tsx` and `StickyBooking.tsx` to handle UI changes based on scroll position. The `StickyBooking.tsx` listener specifically queries the DOM (`document.getElementById('home')?.offsetHeight`) within the scroll event. This can cause layout thrashing and drop frames, as scroll events fire at a high frequency. Next.js 16/React 19 doesn't automatically protect against this.
**Action:** Always wrap scroll event handlers that trigger state updates or DOM queries in `requestAnimationFrame` to throttle execution to the browser's refresh rate. Additionally, add the `{ passive: true }` option to the event listener to allow the browser to process scrolling on the compositor thread without waiting for the main thread.
